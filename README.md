# Flutter Hero Widget Demo

A Flutter travel app demonstrating a Hero
animation between an Explore page and a Detail page.

## Features
- Explore page with a landscape image
- Animated transition to a detail screen
- Back navigation with a reverse animation

## Requirements
- Flutter SDK
- Dart SDK
- Android emulator or Flutter-supported device

## How to Run
1. Clone this repository.
2. Run `flutter pub get`.
3. Run `flutter run`.
